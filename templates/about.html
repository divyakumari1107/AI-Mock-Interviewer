About AI Mock Technical Interviewer & Viva Defense Guide

System architecture, algorithms, and academic concepts for project presentations and viva evaluations.

1. Problem Statement & Research Motivation

Traditional online coding platforms evaluate only binary compilation results ($Passed / Failed$) against input-output pairs. However, real-world technical interviews at tier-1 tech companies evaluate a candidate holistically across:

Problem Clarification
Asking constraints & edge cases
Big-O Derivation
Explaining time/space tradeoffs
Hint Adaptability
Iterating without getting spoon-fed
Code Quality
Clean structure & PEP8 standards

This project implements an autonomous conversational agent simulating a Senior Software Engineer that guides the interview, evaluates code across 4 dimensions, and delivers an objective hiring verdict.

3. High-Scoring Viva Questions & Defense Answers

Code is executed in a dedicated worker process spawned via Python's `multiprocessing` engine with a hard timeout of 2.5 seconds. If the code does not finish within 2.5 seconds, the process supervisor forcefully issues a terminate signal, returning a standard Time Limit Exceeded (TLE) response.

We designed a structured 3-tier progressive hint state machine. Tier 1 delivers a conceptual nudge (e.g. data structure suggestion); Tier 2 delivers an algorithmic approach hint (e.g. two pointers); Tier 3 provides structural pseudocode. The AI system instructions strictly prohibit outputting full runnable solution code.

Using a weighted composite formula: Overall = (Correctness × 40%) + (Complexity × 25%) + (Quality × 20%) + (Communication × 15%). A score of 85+ yields a Strong Hire; 70-84 yields Hire; 50-69 yields Lean No-Hire; below 50 yields No-Hire.
